# Dog Separation Anxiety: Advanced Training Schema

## Schema Overview

Training a dog to overcome separation anxiety requires a structured, repeatable framework. This document defines a **Training Schema** — a formal blueprint that any trainer or owner can follow. The schema is organized into *Phases*, each containing *Protocols*, which in turn have *Steps* with clear *Success Criteria*.

Using a schema rather than ad-hoc training ensures:

- **Reproducibility**: Same approach works across different dogs and trainers.
- **Measurability**: Clear pass/fail criteria at each step.
- **Safety**: Never push the dog beyond its threshold.
- **Adaptability**: Schema can be tuned per dog without losing structure.

---

## Schema Structure

Every training session follows this template:

```
Phase → Protocol → Step → { Action, Duration, Success Criteria, Failure Fallback }
```

### Phase

A major milestone in training (e.g., "Building Independence Indoors"). Phases are sequential — do not advance until the current phase is mastered.

### Protocol

A specific technique within a phase (e.g., "Room Boundary Training"). Protocols within a phase can be practiced in parallel if the dog tolerates them.

### Step

The smallest unit of training. Each step has:

| Field | Description |
|-------|-------------|
| **Action** | What the trainer does (e.g., "Step through the door and close it") |
| **Duration** | How long the action lasts before the trainer returns |
| **Success Criteria** | Observable signs the dog is calm (no whining, pacing, lip-licking, yawning, or escape attempts) |
| **Failure Fallback** | What to do if the dog shows distress (reduce duration by 50%, increase reward value) |

## Phase 0: Pre-Training Assessment

Before starting any protocol, complete this assessment. Do not skip.

### Protocol 0.1: Baseline Observation

**Step 0.1.1 — Record Baseline Behavior**

| Field | Value |
|-------|-------|
| Action | Set up a camera. Leave the house for 5 minutes. Record behavior. |
| Duration | 5 minutes away + review time |
| Success Criteria | N/A (this is data collection, not training) |
| Failure Fallback | If dog panics within 30 seconds, shorten to 20 seconds for assessment |

Document the following baseline metrics:

- [ ] **Latency to first distress signal** (seconds until whining, pacing, etc.)
- [ ] **Intensity** (1 = mild pacing, 5 = destructive panic, self-injury)
- [ ] **Duration of distress** after you return (how long to settle)
- [ ] **Trigger chain** identified (keys → shoes → coat → door → absence)

### Protocol 0.2: Medical Clearance

- [ ] Veterinary exam to rule out: urinary tract infection, gastrointestinal issues, cognitive dysfunction, pain conditions
- [ ] Blood panel if dog is over 7 years old
- [ ] Discuss medication options with vet (fluoxetine, clomipramine) as adjunct therapy

## Phase 1: In-Home Independence

**Goal:** Dog remains calm when owner is in a different room with the door closed.

**Prerequisite:** Phase 0 complete.

### Protocol 1.1: The Settle Command

Teach the dog that calm, stationary behavior is rewarded — independent of your proximity.

**Step 1.1.1 — Capturing Calmness**

| Field | Value |
|-------|-------|
| Action | Sit in a chair. Ignore the dog. When the dog lies down on its own, toss a treat between its paws without making eye contact or speaking. |
| Duration | 10-minute sessions, 3x daily |
| Success Criteria | Dog offers a down within 30 seconds of you sitting, 5 sessions in a row |
| Failure Fallback | If dog demand-barks or paws at you, turn your back. Resume when quiet. |

**Step 1.1.2 — Duration Building**

| Field | Value |
|-------|-------|
| Action | After the dog lies down, wait increasing intervals before treating. Start at 5 seconds. |
| Duration | Build to 60 seconds between treats |
| Success Criteria | Dog stays in a down for 3 minutes with treats every 60 seconds |
| Failure Fallback | If dog breaks the down, reduce interval by half |

### Protocol 1.2: Door Desensitization

**Step 1.2.1 — Door Touch (No Movement)**

| Field | Value |
|-------|-------|
| Action | Walk to the door, touch the handle, return to your seat. No treat if dog moves. Treat generously if dog stays. |
| Duration | 20 repetitions |
| Success Criteria | Dog remains in settle position for all 20 reps |
| Failure Fallback | Start 3 steps from the door instead of touching it |

**Step 1.2.2 — Door Open/Close (No Exit)**

| Field | Value |
|-------|-------|
| Action | Open the door 10 cm, close it immediately, return and reward. |
| Duration | 20 repetitions |
| Success Criteria | Dog stays calm for all 20 |
| Failure Fallback | Reduce door opening to 2 cm |

**Step 1.2.3 — Partial Exit**

| Field | Value |
|-------|-------|
| Action | Step through the doorway, immediately step back in, close the door, reward. |
| Duration | 30 repetitions |
| Success Criteria | Dog stays calm for 25+ of 30 |
| Failure Fallback | Step through but leave door open |

### Protocol 1.3: Out-of-Sight Duration

**Step 1.3.1 — 2 Seconds**

| Field | Value |
|-------|-------|
| Action | Close the door with you on the other side. Count to 2. Return. No reward if dog shows any stress signal. |
| Duration | 2 seconds away |
| Success Criteria | 10 consecutive calm trials |
| Failure Fallback | Leave door ajar by 2 cm |

**Progression Table** (only advance when current step passes):

| Step | Duration | Min Calm Trials |
|------|----------|-----------------|
| 1.3.1 | 2 seconds | 10 |
| 1.3.2 | 5 seconds | 10 |
| 1.3.3 | 10 seconds | 8 |
| 1.3.4 | 20 seconds | 8 |
| 1.3.5 | 30 seconds | 5 |
| 1.3.6 | 1 minute | 5 |
| 1.3.7 | 2 minutes | 5 |
| 1.3.8 | 5 minutes | 3 |
| 1.3.9 | 10 minutes | 3 |
| 1.3.10 | 15 minutes | 3 |
| 1.3.11 | 30 minutes | 2 |

**Critical Rule:** If the dog fails any trial, drop back TWO steps and rebuild.

## Phase 2: Departure Cue Extinction

**Goal:** Pre-departure cues (keys, shoes, coat, bag) no longer trigger anxiety.

**Prerequisite:** Phase 1 complete (30 minutes calm behind closed door).

### Protocol 2.1: Cue Isolation

Identify your dog's specific trigger cues. Common ones:

| Cue | Typical Anxiety Onset |
|-----|----------------------|
| Picking up keys | Mild alertness |
| Putting on shoes | Moderate alertness |
| Putting on coat | Increased alertness |
| Picking up bag | Anxiety spike |
| Walking to door | Panic onset |

### Protocol 2.2: Counter-Conditioning

For each cue, perform the action WITHOUT leaving:

**Step 2.2.1 — Single Cue**

| Field | Value |
|-------|-------|
| Action | Pick up keys. Jingle them. Put them down. Return to normal activity. Repeat throughout the day. |
| Duration | 10-15 repetitions per session, 3 sessions daily |
| Success Criteria | Dog shows zero reaction to keys (no head lift, no ear movement) |
| Failure Fallback | Start with touching keys without picking them up |

**Step 2.2.2 — Cue Chains**

Combine cues in sequence. The key insight: a chain of 4 neutral cues is still neutral.

| Field | Value |
|-------|-------|
| Action | Keys → Shoes → Coat → Bag (in that order). Perform each, pause 5 seconds, then the next. At the end, take everything off and sit down. |
| Duration | Full chain takes ~2 minutes, repeat 5x per session |
| Success Criteria | Dog remains settled through 5 full chains |
| Failure Fallback | Break chain at the point of anxiety; practice that cue in isolation |

## Phase 3: Structured Departures

**Goal:** Actual absences from the home, systematically extended.

**Prerequisite:** Phase 2 complete.

### Protocol 3.1: The Departure Ritual

Standardize your departure to be predictable and boring:

1. Place a stuffed Kong or lick mat in the dog's safe zone
2. Perform departure cues calmly (no emotional goodbyes)
3. Exit without looking back
4. Return calmly (no excited greetings — wait 2 minutes before acknowledging the dog)

### Protocol 3.2: Absence Progression

| Step | Absence Duration | Sessions Required | Notes |
|------|-----------------|-------------------|-------|
| 3.2.1 | 1 minute | 5 | Stay within earshot of home |
| 3.2.2 | 3 minutes | 5 | Walk to end of street and back |
| 3.2.3 | 5 minutes | 5 | |
| 3.2.4 | 10 minutes | 4 | Use camera to monitor |
| 3.2.5 | 20 minutes | 4 | |
| 3.2.6 | 30 minutes | 3 | |
| 3.2.7 | 45 minutes | 3 | |
| 3.2.8 | 60 minutes | 3 | Major milestone |
| 3.2.9 | 90 minutes | 2 | |
| 3.2.10 | 2 hours | 2 | |
| 3.2.11 | 3 hours | 2 | |
| 3.2.12 | 4 hours | 1 | Target for most owners |

### Protocol 3.3: Randomization

Once at 1 hour, randomize absence durations (5 min, 45 min, 20 min, 70 min). This prevents the dog from learning that absences always get longer.

---

## Phase 4: Generalization and Maintenance

**Goal:** Dog remains calm regardless of departure time, day of week, or other variables.

**Prerequisite:** Phase 3 complete (4 hours calm).

### Protocol 4.1: Variable Scheduling

- Practice departures at different times of day (morning, afternoon, evening)
- Practice on both weekdays and weekends
- Occasionally run through departure cues then stay home

### Protocol 4.2: Environmental Variation

- Leave from different doors
- Leave the dog in different rooms
- Practice with and without background music/TV
- Practice with different Kong fillings (novelty helps)

### Protocol 4.3: Regression Protocol

Regression is normal and expected. Triggers include: moving house, schedule changes, illness, fireworks season. When regression occurs:

1. Return to Phase 1, Step 1.3.5 (30 seconds)
2. Rapidly progress through steps that the dog previously mastered (often 2-3x faster)
3. Document the trigger for future reference

## Emergency Protocols

### If the dog panics during training:

1. **Do not rush back** — this rewards the panic. Wait for a 3-second pause in vocalization.
2. Return calmly. No eye contact, no talking.
3. Take the dog outside to eliminate (stress can trigger urination).
4. End the training session. Try again later with a REDUCED duration.
5. Log the incident: what was the duration, what were the stress signals.

### If the dog injures itself:

1. **Immediate veterinary attention.**
2. Suspend all alone-time training until medically cleared.
3. Discuss anti-anxiety medication with your vet.
4. Consider a board-certified veterinary behaviorist (DACVB).

---

## When to Escalate

Refer to a **veterinary behaviorist** or **Certified Separation Anxiety Trainer (CSAT)** if:

- No progress after 6 weeks of consistent schema-following
- Dog self-injures during absences
- Dog breaks through windows, doors, or crates
- Owner cannot be present for Phase 1-2 training due to work
- Medication trial is being considered

## Schema Quick Reference Card

```
Phase 0: Assessment
  → Baseline observation → Medical clearance

Phase 1: In-Home Independence (30 min behind door)
  → Settle command → Door desensitization → Out-of-sight duration

Phase 2: Cue Extinction
  → Identify triggers → Counter-condition each → Chain cues

Phase 3: Structured Departures (target: 4 hours)
  → Departure ritual → Systematic progression → Randomization

Phase 4: Generalization
  → Variable scheduling → Environmental variation → Regression protocol

Emergency: Panic → Wait for pause → Return calm → Reduce duration
Escalate: 6 weeks no progress, self-injury, destruction → CSAT/vet behaviorist
```
